End of the crate

Something small waiting after the last record is flipped down. Each sticker is a live crate that starts near its end: drag down, scroll or use the arrow keys to flip past the last record, and drag up to stand it back. Star one from each group.

What's there

What you find where the last record stood. All of these come from the mark, the crate's own records or the owner's name, so they work for anyone's crate with nothing to set up. "Long name" tries a crate owner with a long name.

Getting back

What happens next. Flipping back always works; these add a way back to the front. Each one uses A1 so they're easy to compare.
